# Codex Switcher 中文修正版

版本：0.2.20-local.2 · macOS Apple Silicon

这是基于 Lampese/codex-switcher 0.2.20 的本地修改版本。上游基础提交：9dec3c18a856abbb545241ae867c5b5ba9d92fa6。未向上游或其他平台发布。

## 开始使用

1. 在“应用程序”打开 Codex Switcher。主页底部应显示“中文修正版 0.2.20-local.2”。
2. 点击“添加账号”，给账号起一个易识别的名称，通过 ChatGPT 登录完成授权。分别添加需要管理的账号即可。
3. 添加或导入只保存账号，不会改变 Codex 当前登录；取消授权后，迟到的回调也不会保存账号。
4. 准备切换时，先结束当前工作，再点击目标账号的“切换”。如果有服务仍在运行，按面板提示处理。

账号密码不需要写入工具。工具保存授权后的登录凭据；凭据失效或被撤销时，需要重新授权。

## 运行中的服务

主页的“运行中的服务”显示本机识别到的 Codex 相关服务，包括名称、PID、父 PID、类型与可执行文件路径；不显示可能包含敏感信息的完整命令行。

每个允许停止的独立服务都有单独的“停止”按钮。点击后会明确显示目标服务与 PID，确认后才发送正常终止请求。正在执行的任务可能中断，请先确认对应工作已完成。不会执行强制杀进程、提权或一键结束所有服务。

桌面客户端、桌面所属后台服务、本工具及其父进程、其他用户的进程，以及身份无法核验的进程，不允许从这里单独停止。面板会显示原因。桌面客户端使用主界面的“关闭桌面”流程。

停止前会再次核验进程的路径、启动时间和所属用户；如果列表已过期或进程身份发生变化，会拒绝执行并提示刷新。服务若被其他程序自动拉起，刷新后可能出现新的 PID。

## 图标与悬浮说明

将鼠标停留在按钮上，或用键盘聚焦按钮，可查看功能说明。

- 眼睛：隐藏或显示账号名称与邮箱，方便截图和共享屏幕。
- 刷新：更新账号剩余额度与订阅信息。
- 闪电：发送少量测试请求来预热账号，会消耗少量额度。
- 更多功能：打开设置、自动预热、定时预热和外观选项。
- 账号：添加账号，或导入、导出备份。

## 设置

- 界面语言：此版本默认简体中文，无需另行设置。
- 菜单栏显示：选择显示图标与短周期额度、短周期与每周额度，或隐藏入口。短周期通常为 5 小时，以账号实际返回的周期为准。
- 程序坞图标：控制本工具是否在 Mac 程序坞显示。至少保留程序坞或菜单栏中的一个入口。
- Codex 退出方式：始终请求正常退出；执行关闭前仍需确认。自动切换流程不会终止独立 CLI、后台服务或 IDE 会话。
- 退出后重新打开 Codex：可每次询问、重新打开，或保持关闭。切换账号时，只有切换成功后才重新打开。

设置面板可滚动，修改选项自动保存。“保持关闭”不会被后台返回的重开标识覆盖。

## 修正范围

- 新增、导入、删除账号不再触发隐式切换。
- 取消或被替换的登录流程不会误保存账号。
- 当前账号以官方登录状态为准，保存最新凭据，避免后台刷新覆盖当前登录。
- 切换前检查运行状态；自动退出仅面向已核验的桌面应用。
- 手动停止独立服务与自动切换流程分开，逐项确认。
- 主页、设置、账号弹窗、菜单和常用提示中文化，日期使用中文格式。
- 关闭上游自动更新，避免覆盖本地修正。

本地账号库沿用上游的本地文件存储方式，并限制文件权限；不是系统钥匙串。导出的账号备份同样含有登录凭据，应妥善保管。
